# 🌤️ Weather App

A responsive weather application built using HTML, CSS and JavaScript.

## Features

- Search weather by city and country
- Current temperature
- Weather condition
- Weather icon
- Humidity
- Wind speed
- Feels-like temperature
- Visibility
- Responsive design
- Error handling
- Loading state

## Technologies Used

- HTML5
- CSS3
- JavaScript
- WeatherAPI

## API

This project uses WeatherAPI to retrieve current weather information.

https://www.weatherapi.com/
